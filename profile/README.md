**Practical cloud engineering, built for clarity and maintainability.**

Hagen Cloud is being built by [João Pedro Hagen](https://github.com/joaopedrohagen) as an independent **Cloud and DevOps consultancy**, focused on infrastructure automation and platform engineering.

This organization brings together reusable infrastructure components and engineering tools, with code, documentation, and explicit validation boundaries.

<br>

**☁️ Engineering focus**

| Area | Focus |
| :--- | :--- |
| Cloud & platforms | AWS, Azure, Kubernetes, and infrastructure architecture |
| Infrastructure as Code | Reusable Terraform components and deliberate change management |
| Automation & reliability | Ansible, Python, CI/CD, observability, and controlled resilience testing |

<br>

**⚙️ Explore the work**

- **[Terraform Modules](https://github.com/hagen-cloud/terraform-modules)** — Reusable building blocks for cloud infrastructure.
- **[MongoDB Atlas Resilience](https://github.com/hagen-cloud/ansible-mongodb-atlas-resilience)** — Ansible tooling for controlled primary failover and Azure regional outage simulations.
- **[MongoDB Atlas Data Seeder](https://github.com/hagen-cloud/mongodb-atlas-data-seeder)** — Python tooling for synthetic data generation and load testing in non-production environments.

<br>

**How the work takes shape**

Focused components, understandable interfaces, and documentation that explains intent. Each project records its own assumptions, validation evidence, and operational boundaries.
